The Collatz step count of n is the number of steps to reach 1, where each step replaces an even n with n / 2 and an odd n with 3n + 1. The step count of 1 is 0.

Print the step counts of 1 through 10, in order. Then print the starting value below 10000 with the largest step count (the smallest such value if several tie), then its step count.

Print each value on its own line, with nothing else on the line.
